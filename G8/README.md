# G8：时限属性与实验数据汇总

## 负责范围

- 为正常模型和故障模型设计时限类验证属性。
- 必要时建立不改变原系统行为的观察者时钟/模板，并说明时限起点和上界。
- 汇总 P0/P1/P2 的原始计数、通过率、错误分布和修复成本。
- 与 G7 共同解释反例，与 G2 核对 Prompt 组别、样本数和生成环境。

## 交接输入

- G1：`G1/02_Prompt对照实验方案.md`、`G1/03_CTL属性与验收矩阵.md` 和实验 CSV 模板。
- G2：15 个 raw 样本、元数据和 AI 使用记录。
- G3/G4：按样本编号整理的错误清单。
- G5/G6：v1/v2/v3 模型及匹配查询、验证输出。
- G7：安全/活性结果和反例分析。

## 建议提交材料

- `queries/`：时限属性查询及观察者版本。
- `时限属性说明.md`：`WAIT_BOUND`、起算点、观察者语义和适用模型版本。
- `实验统计.csv`：可复算的样本级原始数据，不只保存百分比。
- `验证结果.md`：每条时限属性的 SAT/UNSAT/ERROR、工具版本和证据路径。
- `统计结论.md`：三组 Prompt 的原始计数、比例、错误类别和实验限制。

## 关键约束

- 经典 UPPAAL 查询中不要假设存在可直接使用的通用 `within` 关键字；有界响应应通过观察者时钟/模板或等价状态约束表达。
- raw 与 repair 的结果分开统计；前者不能因后续修复而改成通过。
- 缺失或前置阶段失败使用 `N/A`，不能计入通过数。
- 每组样本量为 5 时，同时报告原始计数和百分比，避免作过强统计结论。
