# P1 时间自动机知识增强 Prompt（冻结版 1.0）

> 实验执行时，只发送下面“Prompt 正文”中的内容。不要把标题、组别说明或其他样本输出一并发送。

## Prompt 正文

请为 UPPAAL 5.0.0 生成一个交通灯实时系统模型。

系统包含一个交通灯和一辆车。交通灯按照绿灯、黄灯、红灯循环，持续时间分别为 20 秒、3 秒、20 秒。车辆先接近路口，在 1 到 5 秒内到达等待区，然后等待允许通行；车辆穿越路口需要 2 到 3 秒，最后进入完成状态。

请按时间自动机方式建模，并遵守以下要求：

- 至少建立 `TrafficLight` 和 `Vehicle` 两个模板，并在 `<system>` 中实例化。
- 用 `clock` 表达灯相位、车辆到达和车辆穿越时间。
- 对有最大停留时间的位置设置不变量，并为出口设置相容的卫士条件。
- 在进入新计时阶段时显式复位相应时钟。
- 每个模板必须有明确的初始位置，所有迁移的 source/target 标识符必须存在。
- 全局声明、局部声明、卫士、更新和系统实例应符合 UPPAAL 语法。
- XML 中的 `<`、`>`、`&&` 等内容应按 XML 要求正确转义。
- 查询必须使用模型中实际存在的进程实例、位置和变量名。

请输出：

1. 一个完整的、可保存为 `.xml` 并导入 UPPAAL 的模型。
2. 一组用于检查无死锁、车辆安全通行和车辆能够完成通行的 UPPAAL 查询。

输出格式必须严格为两个代码块：第一个代码块标记为 `xml`，只包含完整 XML；第二个代码块标记为 `text`，每行一条查询。不要在代码块中加入解释、伪代码、省略号或未定义占位符。
