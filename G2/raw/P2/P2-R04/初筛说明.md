# 静态初筛（非UPPAAL验证结果）

XML解析和位置/边引用检查通过，内外查询逐条一致。
五份共同机制：绿灯剩余时间不少于3秒才可进入（相位时钟<=17），进入时复位穿越时钟并置occupied=true，2至3秒后完成并释放occupied。绿转黄仅在20秒且!occupied时允许。
边界静态推理：最晚第17秒进入，最多3秒完成。若恰好第20秒仍在Crossing，车辆退出边已可用，先释放occupied，灯才可切换。这解释了保护机制的意图，但不能代替无死锁和安全查询实测。
Waiting仍可无限等待；P2只要求存在完成路径，不要求所有路径必然完成，因此不能将此单独判为P2需求失败。
首次进入初始位置的时钟默认为0；没有committed初始化位置的模型不因此自动判错。P2关于显式复位的风格要求与运行语义应分别审查。

必须由G3/G4审查需求对应关系，G7运行统一查询。原始查询中的额外占用一致性性质单独报告，不改变跨组评分集合。
