## 目录

- `raw/`：原始提交、提取XML/查询、元数据、初筛说明与检查结果。原始模型不修改。
- `prompts/`：提示词资料。P1/P2来自G1冻结版；P0正文从本聊天已核对版本保存。正式复现应核对G1仓库版本。
- `evaluation/`：另存的三条统一评价查询候选及实例映射，供G7复核运行。
- `docs/G2_个人报告.md`：阶段报告，未虚构实测结果。
- `AI使用记录.md`：实验采集和AI辅助整理说明。
- `slides/`：5页阶段汇报PPT及讲稿。
- `scripts/check_structure.py`：可复现的XML结构初筛，不调用UPPAAL。
- `screenshots/README.md`：待补实操证据清单。
- `15份样本交接索引.csv`：模型索引和未运行状态。

## 使用

运行 `python scripts/check_structure.py`，结果输出为 `structure_summary.json`。此脚本不检查UPPAAL表达式、查询语法或系统行为。

G3/G4先审查raw并保存工具输出；G7复核evaluation后运行，AI自带查询结果另列。修复另存版本，禁止覆盖raw。详见交接说明.md。
