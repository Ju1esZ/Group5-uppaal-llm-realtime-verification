## 使用

运行 `python scripts/check_structure.py`，结果输出为 `structure_summary.json`。此脚本不检查UPPAAL表达式、查询语法或系统行为。

G3/G4先审查raw并保存工具输出；G7复核evaluation后运行，AI自带查询结果另列。修复另存版本，禁止覆盖raw。详见交接说明.md。
